# Diabetes Probability & Statistical Analysis

Streamlit application built around the 100,000-row Diabetes Prediction Dataset.

## Features
- Gender-first patient flow (Male/Female)
- Bayesian / Naive Bayes-style probability calculation using numerical Gaussian likelihoods and categorical likelihoods
- Conditional probability by gender and risk factors
- Descriptive statistics
- Confidence intervals
- Chi-square independence tests
- Interactive Plotly visualizations
- Premium animated UI with custom CSS
